nxcontroller remote

Play the gamepad or type a text file into a Switch or PC through your nxcontroller board, over Bluetooth.

This browser can't use Bluetooth. Use Chrome or Edge on a computer or Android phone, and open this page over https or from localhost.

Connect

Not connected.

The board needs firmware built with Bluetooth. The first connection asks to pair; accept it.

Type it

Hold is the minimum time each key stays pressed and released: 20 ms suits a Switch 2, 0 is fastest on a computer. Text comes out as written: if the Switch or computer has Caps Lock on, the board turns it off first.
