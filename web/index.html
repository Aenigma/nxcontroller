nxcontroller installer

Turn an ESP32-S3 into a WiFi-controlled USB gamepad and keyboard for a Switch or PC.

1. Put the board in flashing mode

  1. Plug the board's USB port into this computer. That's the native port, not the one labelled UART/COM.
  2. Hold BOOT, tap RST, then let go of BOOT.

You have to do this before every install. Until you do, the port you need (USB JTAG/serial debug unit) won't appear in the list at all, because the running firmware turns that port into a controller.

2. Install

Your browser can't flash devices. Use Chrome or Edge on a desktop computer. Flashing needs this page served over https (or from localhost).
  1. Pick USB JTAG/serial debug unit in the port list. Don't pick USB Single Serial, CP210x or CH34x: that's the UART chip, and installing through it fails on many Macs ("Failed to initialize").
  2. On a first install, tick erase. On updates, leave it off to keep your saved WiFi and USB mode.
  3. When it finishes, press RST. The board stays in flashing mode until you do, so the setup hotspot won't appear before that.

If you get "Failed to open serial port", the board left flashing mode while connecting. Reload the page, then keep holding BOOT while you tap RST, click Connect & install and pick the port. Let go once writing starts.

Logs: the native port never shows logs, so the installer's console stays blank there. To watch the board's log, connect to the UART port instead (USB Single Serial and similar) and press RST.

3. Connect it to your WiFi

  1. On your phone or laptop, join the open WiFi network nxcontroller-setup.
  2. The setup page should pop up. If it doesn't, open http://192.168.4.1.
  3. Enter your network's name and password (2.4 GHz only). The board restarts and joins it.

If the board ever can't reach its network for about 30 seconds, the setup hotspot comes back so you can fix the details.

4. Control it

From a computer on the same network, with the nxcontroller Python package:

nxc discover
nxc mode keyboard     # or gamepad / both
nxc type "hello"

On a Switch, register the gamepad with nxc tap L R --duration 0.5 on Controllers → Change Grip/Order.

Or, without Python: use the gamepad or type a text file from your browser over Bluetooth (Chrome or Edge; needs firmware built with Bluetooth).
